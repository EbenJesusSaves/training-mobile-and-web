## Platforms

- API + PostgreSQL 17 (Docker) on macOS, Node 24.21.
- Dashboard: Chrome at 1440×900, 1024×768 and 390×844, light and dark.
- Mobile: bundled and launched in Expo Go (SDK 57) on the iOS 26 simulator (iPhone 17 Pro); the onboarding illustration rendered.
  Full on-device walkthroughs and the side-by-side comparison with the design references are **pending manual testing**.
  Maestro flows for the booking journey are provided in `mobile/e2e/maestro/` but were not completed.

## Known limitations

- Social sign-in is intentionally omitted (no provider configuration); payments are simulated.
- The supplied third design reference (`image(20261003-080319).png`, dark booking/ticket screens) was not attached;
  dark screens were derived from the light references and the dark ticket screen, with the red accent.
- The ticket barcode is PDF417 generated by the API; staff look tickets up by code in the dashboard search (no camera scanner).
- `training/slides/railpass-frontend-course.pdf` is rendered from the same slide content with PDFKit because PowerPoint
  automation was blocked on the build machine; re-export from PowerPoint (File → Export → PDF) for a pixel-identical copy.
  The deck does not yet include mobile screenshots.
- Seeded journeys cover 3 days ago to 21 days after seeding; run `yarn --cwd backend db:reset` or extend the timetable from the dashboard.
